# 王宏威的网页美学

## 适用范围

这套审美用于王宏威的网页作品，包括作品集、项目档案、编辑型页面、媒体实验、互动作品和 CV。先阅读当前作品、用户指定的参考和最新反馈，再按内容决定主角、画面比例和动效范围。视觉层级、留白和交互节奏可以独立使用。采用 CRT 时，按作品需要选择整页屏幕、单个作品窗口或媒体画布，保持屏幕区域内的合成规则一致。页面结构、语言入口和片头由作品需要决定。

## 版式与交互

- 每个主要画面先确定一个主角，可以是姓名、作品、影像或主要操作。用字号、字重、栏宽、对齐和留白组织层级。优先开放式排版，作品或阅读本身需要容器时再使用边框。装饰编号、空标题和重复导航都省去。
- 动效整体放慢，给入场、停留和退出明确的节奏。用现有分隔线承载 D7 信号线。进入视口时单次扫过，前沿清楚，尾部渐暗，最后回到静态。它与 CRT 的连续水平扫描纹独立。数字需要滚动时，进入视口后像计数器一样变换一次，停在真实值。
- 交互采用 **Hollow（字形镂空）+ 闪烁**。用于 CRT 界面里的语言、按钮、标签与可点击链接。静止且未选中时显示实心标签文字，背景透明、无外框。悬停、键盘聚焦或选中时显示实色直角矩形，用文字的字形从矩形中挖空，让屏幕底色和底层内容透过字形。移出或失焦后，未选中项回到无框状态，选中项保留镂空底块。触屏用按下和选中状态提供同样的反馈。
- 实现 Hollow 时保留原生按钮或链接、可访问名称与点击区域。可在独立的视觉层用 SVG 亮度遮罩，以白色矩形保留底块、黑色字形扣除对应像素。保持镂空内部透明，将脉冲施加到挖空后的整个底块和它的光晕。开启「减少动态效果」时保留静态镂空与键盘反馈。
- 2K 宽屏验证 2560 × 1440。让网格与留白利用可用宽度，同时控制正文行长。手机上自然叠放，允许长标题换行，保留语言选项和页尾链接的触控面积。
- CV 的已确认版式可用于同类页面。桌面左侧姓名和自我介绍为第一层级，右侧教育为第二层级，使用开放双栏。姓名与别名有空间时同一行，自我介绍省去重复的小字号别名。经历左侧放日期与地点，右侧放标题和描述，采用对齐分区，省去装饰性时间轴。中文月份写成「7月」，地点写成「中国·杭州」「意大利·米兰」。页头语言和主题控件放右上角。页尾只保留清楚可读的邮箱与作品集链接。履历用职责、方法与结果写清独立制作、合作或小团队管理，三语事实一致。

## CRT 的渲染结构

### 内容坐标与屏幕坐标

- 把作品内容放在可以滚动、位移、旋转、缩放的层。把 RGB 荧光粉、水平扫描纹、颗粒放在独立的屏幕层，图案原点锁定在显示区域的左上角。全页模式用视口坐标，局部作品窗口用窗口坐标。显像管弧度的中心和边缘也由这个区域的边界决定。
- DOM 方案把屏幕纹理层放在滚动层和透视容器之外，作为同级层覆盖显示区域，设 `inset: 0` 和 `pointer-events: none`。全页纹理固定在视口。局部纹理绝对定位在窗口内。祖先上的 transform 或 perspective 会改变 fixed 的包含块，因此只给内容分支加变换。
- WebGL 方案从片元在画布中的位置求屏幕坐标。用画布物理像素与 CSS 尺寸的比例换算为 CSS px，再用 `pitch` 求屏幕图案周期。内容采样可以使用弯曲后的 UV，纹理采样继续使用屏幕坐标。点阵间距从 3 px 调到 9 px 时，必须能看出图案周期变粗。遮罩支持 RGB 竖条、点阵和关闭。
- 需要可选文字、可访问链接、表单或后台实时预览时保留语义 HTML。可用 CSS 叠固定栅格、多层辉光，SVG 位移实现弧度，随区域尺寸或弧度参数变化才重建位移图。独立图像和视频可用 WebGL 实现双尺度辉光、RGB 分离、颗粒和视频残影。莫尔纹作品用两层真实采样的图案调整夹角与相位，保留叠加产生的干涉。

## 明亮模式与暗色模式

CRT 主题同时提供明亮模式和暗色模式。暗色为首次打开时的默认值。已有项目沿用它的主题约定与已保存选择。两种模式共用版式、屏幕坐标、弧度、栅格间距、动效与脉冲时钟，分别定义底色、信号色、辉光和纹理合成。

### 暗色模式

- 页面与 Logo 开场使用纯黑 `#000000`。文字、Logo 和有效图像信号产生辉光。先合成信号与近远两层辉光，再在线性光中按亮度染色。可用 `Y = dot(rgbLinear, [0.2126, 0.7152, 0.0722])`，把原信号与 `Y * filterColorLinear` 按滤镜强度混合。默认滤镜为 `#44FF00`、55%。绿色来自亮信号，零信号始终为纯黑。
- 栅格可用乘法调制亮信号。开场四边和空白区域保持纯黑，省去绿色底板、整屏色雾和装饰性边框。Hollow 激活底块用暗色主题的信号色，字形透明，露出黑底或下层内容。Logo 光晕和激活底块继续按同一时基频闪。

### 明亮模式

- 页面与 Logo 开场使用纯白 `#FFFFFF`。文字和 Logo 核心用纯黑 `#000000`，近处辉光和远处扩散也用黑色，通过透明度渐隐到白底。Hollow 激活底块用黑色，字形透明，在白底上呈白，叠在内容上则露出对应内容。悬停、聚焦、选中和 Logo 频闪继续生效。
- 固定点阵、竖条和扫描线转为灰阶调制。CSS 可用 `mix-blend-mode: screen` 让亮纹调制黑信号，纯白空白维持原值。明亮模式的实际渲染停用彩色滤镜和 RGB 错位。保留存储值，切回暗色时恢复原来的染色、错位和其他 CRT 参数。分别控制底色、信号、辉光与纹理，避免用整页反相处理图像和视频。屏幕之外的独立媒体保留原色。

### 切换与预览

- 用一个主题状态驱动正文、Logo 开场、语言与其他 Hollow 控件、滚动条和预览。提供可用键盘操作的切换按钮，给图标可访问名称并暴露当前状态。进入正文前也能切换时，让开场与正文按钮读写同一状态。首次渲染前读入保存值，同步原生控件的 `color-scheme`，避免刷新时先闪出另一种底色。
- 切换只更新渲染参数。保留语言、滚动位置、选中项、Logo 的动画进度和脉冲相位。有后台时用同一个公开渲染器预览两种主题，包括重播与常驻 Logo。后台预览可以临时切换，访客的明暗选择作为本机偏好独立保存。

### 辉光、色边与颗粒

- 辉光由近处清楚的亮核和远处柔和的衰减组成，亮度和扩散半径分别可调。提高扩散时光晕铺得更开，保持渐隐的外缘。RGB 错位开启时只在有实体覆盖的字形或 Logo 边缘分离红、蓝通道。以亮度和 Alpha 双重限制色边，保留字形核心，省去远处光晕上的白边、彩色闭环或重复轮廓。默认错位为零。
- 扫描线强度为零时水平条纹关闭。颗粒只调制有效信号，黑底高颗粒时仍保持黑边。「小字清晰」独立可切换，开启时只收敛小字的光晕和色边，标题、Logo、屏幕弧度和点阵继续生效。

## Logo 进场与语言

- 使用原始 SVG 轮廓与宽高比。有分片动画素材时复用其分片和轨迹。已确认的八片开场使用平移、三维旋转和镜头拉远，删除景深模糊。收尾以较小的 Logo 居中。复用该开场比例时，宽屏可用 `min(23.5vw, 270px)`，600 px 以下可用 `min(28vw, 136px)`。全屏开场沿用当前主题的纯色背景，开场容器无边框或装饰性外框。
- 显示层用以下结构。飞入中移动镜头、Logo 或单片，屏幕纹理始终留在同一个屏幕坐标。SVG 的每片只绘制图形本身，荧光粉图案通过上层栅格显出。片头和内容页共用参数、主题、屏幕纹理原点与脉冲时基，页头 Logo 进入同一发光系统。

```text
固定的开场显示区域
  镜头（透视和移动）
    Logo
      SVG 分片（位置与旋转）
  屏幕栅格（覆盖显示区域，和镜头同级）
  语言控件（独立于镜头）

固定的正文显示区域
  曲面与信号合成层
    可滚动的 HTML 或媒体
  屏幕栅格（覆盖显示区域，在滚动层之外）
```

- 如果作品把选语言作为入场动作，先淡入开场，完整播放飞入，Logo 停稳后在正下方淡入 `中文 / ENG / ITA`。选择后淡出并进入对应语言。已有开场参考淡入 360 ms、菜单淡入 260 ms、退场 440 ms。这个流程的公开界面省去跳过按钮和 Escape 直达，首次选择记入当前标签会话，记住上次语言和主题。减少动态效果时直接显示静态 Logo 和可操作的语言按钮。其他作品按自身导航需求决定是否使用这段流程。
- 开场语言按钮平时只有无框标签，悬停或键盘聚焦时只把对应项切换为直角填充、字形镂空与底块频闪。正文语言按钮对当前语言持续保留这个状态，其他项在悬停、聚焦或触摸按下时进入。选中底块与 Logo 共用脉冲相位。

## 频闪、性能与后台

- 频闪调制局部辉光，正文基础亮度保持稳定。使用同一时间原点，以 `10000 / rate` 得到毫秒周期。默认 `rate = 127`，即 12.7 Hz、约 78.74 ms。一个周期 0–20% 保持发光峰值，20–64% 逐渐衰减，64–100% 回到低谷。可见标题、Logo 和激活控件加入时沿用当前相位。调「辉光闪烁」应改变深度，调「脉冲速度」应改变周期。
- **Logo 本身要闪烁。** 片头 Logo 从飞入时开始发光脉冲，组装停稳及等待选择语言时继续。正文页头 Logo 在可见时持续脉冲，鼠标移开后仍保持，后台常驻 Logo 预览也沿用同一节奏。给 Logo 单独的发光通道，以 SVG 轮廓或 Alpha 作为光晕来源，让贴近轮廓的辉光随相位衰减，保留可辨识的实心核心。将发光脉冲、Logo 位移和片头整体淡入淡出分开，固定栅格始终留在屏幕坐标上。暗色用当前信号的辉光，亮色用黑色光晕。
- 只为可见、符合条件的元素运行动态。元素离开视口、标签页隐藏或被开场盖住时暂停或回收对应动画。启用减少动态效果时保留静态辉光和完整交互。滚动只移动内容，固定栅格与弧度图复用。快速拖动滑杆时合并为每帧一次更新，只发送改变的效果参数。
- 有后台时用实际公开渲染器做实时草稿预览，保持预览内可滚动，保存后才发布。编辑菜单提供页面动效、独立「小字清晰」、各 CRT 参数和「恢复默认参数」，保留 D1–D7 选项。提供「重播当前屏」「重播 Logo」「常驻 Logo 预览」。常驻默认关，只影响编辑视图。公开页面省去效果面板和暂停动效控件。采用复古滚动条时把直角轨道和有纹理的滑块放在右侧，后台范围滑杆使用普通控件。
- 已有工作经历编辑器可以给每条经历提供独立的 SVG Logo 槽，支持上传、替换、删除和尺寸调整，沿用已有经历的数据结构。SVG 经校验后作为继承当前文字颜色的遮罩，保持比例，放在条目标题后面。参与同一主题、染色与发光，尺寸调整可用 12–72 px 的既有范围。

## 完整 CRT 恢复默认值

以下是已确认的个人 CRT 预设。应用到新作品时从这里开始，已有作品优先读取它保存的值。点「恢复默认参数」时从同一份定义更新所有 CRT 控件和预览。

```json
{
  "motion": "D7",
  "mask": "stripes",
  "pitch": 3,
  "phosphor": 54,
  "scan": 0,
  "curve": 22,
  "glow": 136,
  "spread": 51,
  "flicker": 57,
  "rate": 127,
  "chroma": 0,
  "noise": 0,
  "vignette": 6,
  "color": "#44ff00",
  "tint": 55,
  "clearSmallText": false
}
```

- `motion` 是 D7 信号线扫描，`mask` 是 RGB 竖条，`pitch` 用 px，范围 3–12。 `rate` 以十分之一 Hz 储存，范围 5–300，界面显示 0.5–30.0 Hz。
- `phosphor`、`scan`、`curve`、`flicker`、`chroma`、`noise`、`vignette` 是荧光粉强度、扫描线、鱼眼、辉光闪烁、RGB 错位、颗粒、边缘暗角，范围 0–100%。 `glow` 辉光范围 0–220%，`spread` 光晕扩散和 `tint` 滤镜强度范围 0–200%。 `color` 是滤镜颜色，`clearSmallText` 是小字清晰。

## 验收步骤

1. **测纹理坐标。** 在内容层放一个 200 × 100 px 的纯亮测试块，临时关掉脉冲、颗粒、弧度和辉光，设明显的 RGB 竖条与扫描线。截取测试块内部固定在屏幕坐标上的 44 × 32 px 区域。给内容平移 3 px、旋转 5°，让测试块仍完全覆盖该区域，再截同一区域。比较 RGBA，像素应相同。对正文滚动也做一次同样的测试。最后播放真实 Logo，目测分片从同一组栅格上经过。
2. **测参数是否生效。** 从 3 px 改到 9 px 查看栅格周期，扫线从 0% 拉高应出现水平条纹。分别调辉光、扩散、频闪和频率，核对光晕强度、半径、脉冲深度和周期。给 RGB 错位与颗粒临时加高，检查字形只有近缘色差，远处无闭环，暗色空白仍纯黑。切到亮色，检查白底、黑字、黑晕和无彩色残留。逐项核对恢复默认值。
3. **测 Hollow 和控件频闪。** 分别用鼠标、键盘和触摸操作。未激活项无框，激活项有实色直角底块。可在测试时给按钮后方放双色底图，确认两种底色均能穿过字形。固定高、低两个脉冲相位取样，确认变化发生在底块和光晕上，字形仍镂空。移出后核对未选中与选中项各自的状态。
4. **测开场和 Logo 频闪。** 观察片头四边、淡入淡出和 Logo 到位后语言出现的顺序。在飞入、停稳、正文页头及后台常驻预览分别检查 Logo 光晕的峰值和低谷。页头检查时将鼠标移开。暂停测试时钟，在同一时相比较 Logo 与当前激活控件的脉冲。把频闪调到 0 验证光晕变为静态，调整速度验证周期变化。启用「减少动态效果」后检查仍可进入与交互。
5. **测明暗切换。** 在开场、正文及后台预览分别切换两种主题。截取屏幕空白处，核对暗色为 `#000000`、明亮为 `#FFFFFF`。在明亮模式检查文字、Logo、光晕和 Hollow 底块为黑色或灰阶，字形仍可透出背景，频闪仍有峰谷。先把暗色滤镜和 RGB 错位调到明显值，切到明亮确认彩色残留消失，切回确认原值恢复。检查切换过程中语言、滚动位置和 Logo 进度，并刷新核对主题选择。
6. **测交付。** 在窄屏和 2560 × 1440 检查阅读行长、长语言标签和媒体控件。后台修改后检查草稿预览、保存后的公开效果和重开后的持久化。用实际渲染检查帧率和滚动，确认隐藏标签页或离屏后无持续更新。
